# Primitive map audit — 2026-10-04

Read-only audit of `KamranAsif/Godmode.exe-roguelite`, source commit `333ab8333a60b319e8a873fd568fd392313164c2` (`origin/main` when fetched). No game source edits, asset generation, bake, or PR. All screenshots are native **1920×1080** rendered GodotJS captures, windowed at **[-10000, -10000]**, using an owned `godot-cli game run --fixture roguelite --offscreen --offscreen-size 1920x1080` instance. The instance was stopped after capture. Existing imported resources and the published lighting atlas were reused; no lighting was recalculated.

The list ranks **normal player eye-level visibility**, considering route proximity, height, repetition and object size. Roof free-flight close-ups make equipment inspectable; they do not imply rooftop prominence during normal play. Counts refer to the current DUMBO arena, not every historical mode or the total number of mesh nodes. A merged batch can contain hundreds of props. “Strong/Good” means a small distinct Hunyuan candidate; “Keep” means procedural geometry is appropriate. This is a replacement recommendation, not a claim that every native authored mesh failed its art audit.

## Inactive definitions and generator coverage

`module-counts.json` records **every registered module**, including zero-placement definitions. `stand_in_modules.ts` has zero placed stand-ins: real role candidates suppress them in `ModuleRegistry.forRole`. Standalone ducts/elbows, dishes, hatches, roof railing detail variants and older facade alternatives currently have zero catalogue placements. They are not missing close-ups of visible objects.

`tools/maps/sands-pearl/rich-buildings.mjs` creates legacy box HVAC plus cylindrical vents; `street-detail.mjs` creates primitive lamps/hydrants/bollards. `arena_modules.ts` hides the old `RoofEquipment`, `RoofEquipmentDetail`, `RoofBarrier`, facade and crossing groups, while the arena loader hides replaced street-prop groups. Runtime snapshot contained **185 RoofEquipment-named mesh nodes and zero visible in tree**. Connected roof-service generator parts (handler/fan/duct/exhaust and supports) are likewise in those hidden layers. `maintenance-site.mjs` defines two small office/trailer structures outside the active inland arena. Legacy garage/pocket, test showcase, palette probes and room/debug-stage primitive geometry are not active DUMBO dressing; they are excluded from the placement priority list.

The source scan includes direct Godot constructors (`BoxMesh`, `CylinderMesh`, `SphereMesh`, `PlaneMesh`, `PrismMesh`, `ImmediateMesh`, `SurfaceTool`), `ArrayMesh.add_surface_from_arrays`, `FacetBuilder` helpers and offline box/cylinder/polygon generators. Scanning only Godot class names would miss almost all generated environment modules.

- **Runtime prop emitters:** `street_dressing_geometry.ts`; `environment_modules/{street_furniture,entry_street_details_modules.generated,garden_yard_modules.generated,yard_shed_lamp_modules.generated,roof_details_modules.generated,concept_variants_modules.generated}`; `client/{western_block_dressing,western_block_street_kit,environment_ground_details}`; `dumbo_cordon_visuals.ts`; `environment_detail.ts`; `environment_modules/{waterfront_pier,waterfront_railing}` and `client/waterfront_batches.ts`.

## Count and capture receipts

`module-counts.json` stores source placements and example coordinates; `runtime-summary.json` records fitted hardware counts, hidden roof-equipment nodes, render window and runtime counters; `capture-receipts.json` records camera/target poses. The source scan files preserve all constructor/helper hits for coverage review. Counts of individual assemblies are not inferred from a merged mesh's triangle count. Module manhole/grate totals use emitted fitted-mesh nodes after clipping, not pre-fit candidates.

All PNGs have their native dimensions and SHA-256 in `capture-index.json`. Some context captures are occluded or contain no distinct requested object, as explicitly flagged above. These are the remaining limits of the read-only capture audit; source build counts alone do not prove visibility. No images were submitted to Hunyuan or Meshy.
