# Moving sun-shadow filter comparison

At 100%, no obvious filter-quality difference is visible in the inspected moving-shadow sequences. At 200%, SOFT_LOW has slightly grainier/rougher soft edges; SOFT_HIGH and SOFT_MEDIUM look very close. Only the filter varies within the HIGH graphics preset. Live AI paths and poses differ slightly between levels.
