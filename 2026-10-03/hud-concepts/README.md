# BattleDuty-aimbot HUD concepts

Four image-generated concept previews for Kamran's approval. These are art proposals; no game HUD code was changed. Generated using the built-in image generation tool, with real HUD-less game captures, Kamran's private layout sketches, the earlier overlay content specifications, and the current main-menu trainer screenshot as references.

- [HUD 1 — smoked glass, calm waterfront](hud-01-smoked-glass.png)
- [HUD 2 — ivory graphite, fight](hud-02-ivory-graphite.png)
- [Tab 1 — smoked glass](tab-01-smoked-glass.png)
- [Tab 2 — ivory graphite](tab-02-ivory-graphite.png)

Each image has its full generation prompt and any final revision prompt in the adjacent `.prompt.md` file. Native image output is 1672 × 941, approximately 16:9, preserved without resampling. The scenes and guns remain recognisable; these generated previews are not pixel-exact runtime captures.

Ready killstreak slots 1 and 4 have raised green tabs and original gold-lit icons. Disabled slots 2, 3 and 5 are lower grey cards with numbers only. Chat is a placeholder floating over the lower kill feed, or the scoreboard's right edge. The Tab cheat engine is a separate foreground desktop window overlapping the scoreboard. Chat and cheat windows use the charcoal/lime main-menu application chrome as their visual reference (`scripts/client/desktop_trainer.ts`; existing trainer capture `2026-10-01/10-trainer-maximized-cbd0b508ec.png`).

In-run concepts include crosshair/hit marker, damage direction and low-ammo/reload prompt. No health or armour bars, timers, run-state counters, killstreak progress, supply timer, boss bar or active-cheat chips. Fictional player/chat names and original icons only; third-party crops informed layout only.
