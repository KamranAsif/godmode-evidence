# Chain 31 integration and #909 shaded bridge audit

**PASS for the blocking-defect integration gate.** Chain 31 improves geometry and composition against main 2834f3271. Earlier preview passes survive the inspected integration views. No new blocking arena hole, path break, floating closure, missing waterfront landmark or lost facade detail was found. Remaining concept gaps are backlog below. Final whole-map baked lighting remains a separate gate.

## Reproduction

- Chain: `lanec/chain31-909`, pinned `805c119d09e411b45ffcc3b0688d31c916286838`, on main `2834f32718519030699207bae8660302a427518a`. No game changes or merges.
- 61 fresh 1920 x 1080 renders on each head: seven concept-study cameras, five historical context cameras, ten area street/front views, sixteen gates, four park/pier/underbridge views, nine shore views, seven vehicle views and three outward-looking trim checks. [Camera definitions](views.json), [capture manifest](capture-manifest.json), [metadata](audit-metadata.json).
- Own worktree, own named godot-cli sessions/instances, rendered offscreen on the Windows GPU; FOV 75, photo mode, HUD hidden. Runtime camera position/aim/FOV checked for each capture. Both owned instances stopped after capture.
- Both sides UNBAKED. Chain runtime reported stale lightmap fallback (`stale:663`, first `BuildingMasonry/masonryTan_-10_-3`); main explicitly disabled binding with `GODMODE_STUDY_UNBAKED=1`. The comparison judges geometry and composition, not final AO, shade readability or baked colour.
- [Concept / main / chain sheet](concept-main-chain31.jpg). Inland concepts are quality/composition references with different geographic framing; they are not pixel-aligned to c01-c05. Waterfront 06/07 retain the approved study framing.
- [All comparison sheets](#comparison-sheets); full-resolution PNGs for both heads are linked by camera below. The historical old02/old05 cameras still expose the inherited city trim outside the arena/context margin; no new arena-facing hole was found.
